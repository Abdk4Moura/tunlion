Tunlion Android Redesign

Static mockups for the proposal in docs/design/android-redesign/README.md. Each frame is about 360 by 760 CSS pixels. The numbered pins match the notes beside each frame, and every note names the README section it implements.

All device names, people and keys are fictional examples. Every state shown comes from a field the shared core returns today, unless the frame is marked Not wired or a note says not available yet.
